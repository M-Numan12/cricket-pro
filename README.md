# 🏏 Cricket Pro

A modern, responsive cricket tournament management and live scoring platform for leagues, clubs, academies and tournament organizers.

## Features

- Tournament dashboard
- Multiple tournaments
- Team and squad management
- Player profiles ready for extension
- Live match scorecard
- Ball-by-ball scorer controls
- Points table and NRR display
- Batting and bowling statistics
- Responsive desktop/mobile UI

## Run locally

No build step is required for this first version. Clone the repository and open `index.html`, or serve the folder with any static web server.

## Roadmap

The next production phase can add authentication, persistent database storage, image uploads, automatic innings/overs logic, full scorecards, tournament scheduling, role-based admin/scorer access, notifications and deployment.
